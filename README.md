# React DataGrid - Demo Website

This is the interactive demo website for [react-open-source-grid](https://www.npmjs.com/package/react-open-source-grid), showcasing all the features and capabilities of the DataGrid component.

## Live Demo

Visit the live demo at: [https://bhushanpoojary.github.io/react-open-source-datagrid-view/](https://bhushanpoojary.github.io/react-open-source-datagrid-view/)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Features Demonstrated

- Standard DataGrid with pagination, sorting, filtering
- Virtual scrolling for high-performance rendering
- Infinite scroll with server-side data
- Live market data streaming
- Tree data with hierarchical rows
- Row dragging and reordering
- Row pinning (sticky top/bottom)
- Cell renderers and custom components
- Column filters (advanced filtering)
- Faceted search
- Context menus
- Tooltips
- Layout persistence
- Theme system (10+ built-in themes)
- Density modes
- Pivot tables
- Advanced cell editors
- Integrated charts
- Master/Detail expandable rows
- Group By with aggregation
- Server-side features
- Full accessibility (a11y) support
- Grid API reference and interactive demo
